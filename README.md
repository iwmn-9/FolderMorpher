# AstraSize — All-in-One Enterprise Storage & Migration Suite

Windows 11のFluentデザインと人間工学（長時間でも疲れにくいライトテーマ）を融合させた、**ファイルサーバー管理・移行・容量分析・権限台帳**を一括完結する企業向けオールインワンデスクトップアプリケーションです。

C# (.NET 8 + WPF) ネイティブで構築されており、ランタイム同梱の単一実行ファイル（`AstraSize.exe`）としてダブルクリックするだけで即座に起動します。

---

## 🌟 4大コア機能（タブ切り替え）

### 1. 📊 容量分析 (Storage Explorer)
- **実ドライブ & UNCパス対応**: `C:\` 等のローカルドライブに加え、ファイルサーバーのUNC共有（`\\server\share` や `\\192.168.x.x\share`）を直接指定可能。
- **動的インサイト連動**: ツリーでフォルダを選択すると、右ペインの「肥大化ファイルTop 10」および「拡張子別内訳」がそのフォルダ配下だけに即座に絞り込まれて再集計。
- **容量推移 (Storage Trend)**: 過去のスキャン履歴を自動記録し、前回スキャンとの容量増減（`+X GB ▲` / `-X GB ▼`）をリアルタイム判定。「📈 容量推移」ボタンから過去履歴を一覧表示。
- **Excel/CSVレポート出力**: スキャンした全構造をBOM付きUTF-8形式でワンクリックエクスポート。

### 2. 🛡️ 権限台帳 & シミュレーション (ACL & Ledger)
- **NTFSアクセス権の自動解析**: ドメイン参加PCから管理者権限で対象パスのセキュリティ記述子（ACL/ACE）を階層走査。
- **Excel台帳 (マトリクスCSV) 自動出力**: 
  - 手作業でのExcel台帳コピー・更新を完全撤廃。
  - 「縦軸＝フォルダ階層」「横軸＝ユーザー/グループ」「交点＝権限（フルコントロール/変更/読み取り/継承）」の美しいマトリクス形式で自動出力。
- **安全なシミュレーション (Dry-Run)**:
  - 「もしこのグループに権限を与えたらどうなるか？」を実環境に触れずに事前検証。
- **変更前スナップショット & 1クリックロールバック**:
  - SDDL形式でACLを瞬時にバックアップ。万が一の設定ミス時も過去状態へワンクリックで完全巻き戻し。

### 3. 🚀 サーバー移行 & ガワ作成 (Server Migration)
- **空フォルダ (ガワ) ＋ 権限の先行作成**:
  - 数TBの実ファイルを転送する前に、フォルダ構造とアクセス権だけを移行先に一瞬で複製。
  - 事前のアクセス権確認やリハーサルが即座に可能。
- **Robocopy 最適化コマンド生成・実行**:
  - 企業ファイルサーバー移行のベストプラクティス（マルチスレッド `/MT:16`、アクセス権同期 `/COPYALL`、ミラーリング等）を自動構成。
  - ワンクリックで管理者コマンドプロンプトを立ち上げて実行可能。
  - 移行元と移行先をUNC指定することで、作業端末をハブにせずサーバー間で直接高速転送。

### 4. 🔗 リンク修復 (LinkFixer)
- **ショートカット (`.lnk`) 一括修復**: サーバー移行に伴い参照先が切れてしまうデスクトップや共有フォルダ内のショートカットを検索し、新パスへ一括置換。
- **Excel (`.xlsx`) 外部リンク修復**: ブック内に埋め込まれた他ブックへの外部リンクパスを自動検出し、新サーバーパスへ修正。
- **シミュレーションモード**: 実際に書き換える前に、置換候補となるファイルをプレビュー確認可能。

## 🚀 起動方法

### 方法1: exeを直接ダブルクリック（推奨）
プロジェクトフォルダ直下の **`AstraSize.exe`** をダブルクリックしてください。

### 方法2: バッチファイルから起動
プロジェクトフォルダ直下の **`AstraSize.bat`** をダブルクリックしてください。

## 🛠️ 技術スタック
- **言語 / フレームワーク**: C# (.NET 8.0 Windows Desktop SDK) / WPF
- **UIアーキテクチャ**: Fluent Light Design、XAML DataGrid/TreeView、マルチスレッド非同期バインディング
- **ストレージAPI**: Win32 `GetDiskFreeSpaceEx` (P/Invoke)、`System.IO.Enumeration`
- **セキュリティ / 移行**: `System.Security.AccessControl` (NTFS ACL / SDDL)、`Robocopy`、`WScript.Shell` (COM)
