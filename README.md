# FolderMorpher — Storage Monitor & Migration Studio

Windows 11のFluentデザインと人間工学（長時間でも疲れにくいライトテーマ）を融合させた、**日常のファイルサーバー容量監視**と**新環境への移行・仮想フォルダツリー設計・権限設計・N対1統合**を一気通貫で完結するプロフェッショナル向けデスクトップアプリケーションです。

C# (.NET 8 + WPF) ネイティブで構築されており、ランタイム同梱の単一実行ファイル（`FolderMorpher.exe`）としてダブルクリックするだけで即座に起動します。

---

## 🌟 主要コア機能

### 1. 📊 日常の容量分析・監視 (Storage Monitor)
- **親比占有率メーター**: 「1つ上の上位フォルダに対して何％使っているか」を一目で直感把握できるプログレスバー＋白太字パーセント表示（高コントラスト設計）。
- **マルチタブ機能**: 複数フォルダや別サーバー（UNC共有 `\\server\share`）をタブごとに同時スキャン・並行比較。
- **動的インサイト連動**: ツリーでフォルダを選択すると、配下の「容量上位ファイル Top 10」および「拡張子別内訳」が即座にドリルダウン集計。
- **容量推移ベクターグラフ (Storage Trend)**: 過去のスキャン履歴を自動記録し、前回との増減（`+X GB ▲` / `-X GB ▼`）をリアルタイム判定。専用ウィンドウで美しいベクターチャートを描画。
- **クイック連携**: ツリー上で右クリックして「🛡️ 実環境 権限コントロールで開く」を選択すると、対象フォルダの権限管理画面へ1発ジャンプ。
- **サブフォルダ単体ドラッグ＆ドロップ**: 現行ツリーの深い階層のフォルダを、親フォルダを巻き込まずに単体で移行設計エリアへDnD可能。

### 2. 🛡️ 実環境 権限コントロール (Live ACL Manager)
- **事故を起こさない分離設計**: 仮想ツリーを設計する「移行シミュレーション」とはタブを明確に分離し、既存の実ファイルサーバー/フォルダの権限を安全に管理。
- **シミュレーションと共通の快適操作**:
  - ADプリンシパル一覧からドラッグ＆ドロップで即座に権限カードを追加。
  - カードのダブルクリックで「Windowsセキュリティの詳細設定（基本6＋高度14項目連動）」を開いて柔軟に編集。
  - ゴミ箱ゾーンへドラッグ＆ドロップで直感的に権限を削除。
- **安全な即時適用 & SDDL自動スナップショット**:
  - 実環境への「⚡ 即時適用」を実行する直前に、現在のセキュリティ記述子（SDDL）を自動でバックアップ。
  - 何か問題があれば「ワンクリック復元」で直前の安全な状態へ即座にロールバック可能。
- **マトリクス台帳CSV出力**: 現行のアクセス権一覧を監査・報告用のCSV台帳としてワンクリック出力。

### 3. 🗂️ 仮想モックツリー設計 & 直感DnD階層操作 (Migration Studio)
- **サルでも迷わない直感DnD**:
  - **行直ドロップ**: 閉じたフォルダ行にそのままドロップするだけでサブフォルダ化。
  - **アコーディオン展開パネル**: フォルダをクリックすると「サブフォルダ化ゾーン」「N:1統合エリア」「AD権限カード」が展開。
  - **自由自在な階層移動**:
    - 同一階層の別フォルダにDnDしてサブフォルダ化（階層下げ）。
    - ドロップ時の左ずらし幅、またはクイック操作ボタン（`⏮ ルートへ一気ジャンプ` / `◀ 昇格` / `▶ 降格`）で何階層からでもワンタップ移動。
  - **ポイ捨て削除**: ゴミ箱ゾーンへドラッグ＆ドロップするだけで、権限や紐づけを直感的にポイ捨て解除。

### 4. 🔗 現行と新環境の紐づけ・N:1統合マッピング
- **複数フォルダの統合**: 「営業部A」「営業部B」を新環境の「営業部」にひとまとめにするようなN対1マッピングを完全サポート。
- **自動紐づけ & 手動追加**: 現行ツリーから持ってきた場合は自動で元パスが記憶され、追加の移行元もドロップするだけで統合可能。

### 5. 👥 移行先セキュリティ権限設計 (ACL)
- **RSAT不要**: LDAP/ADSI経由でドメインコントローラーからユーザー・セキュリティグループを直接取得・キャッシュ。
- **カード型DnD付与**: AD一覧から権限カードをフォルダへドラッグするだけで権限付与。
- **Windows「セキュリティの詳細設定」完全準拠**:
  - カードのダブルクリックで詳細編集モーダルがポップアップ。
  - **基本6項目**（フルコントロール、変更、読み取りと実行、フォルダーの内容の一覧表示、読み取り、書き込み）と**高度なアクセス許可14項目**（走査/実行、データの読み取り、属性の読み取り、所有権の取得など）が**完全双方向リアルタイム連動**。

### 6. 🔍 人間向け「現行 vs 新環境」変化点差分インスペクター (Diff Review)
- **人間のための差分対比レビュー**:
  - 「現行と新環境で何がどう変わったか？」を一目で把握できる専用インスペクター。
  - 4つの変更種別（`🔀 統合 (N:1)`、`📁 階層移動`、`✨ 新規作成`、`🗑️ 廃止/未割当`）をカラーバッジで分類。
  - 旧パス vs 新パス、変更前後のACL権限の増減差分、推定データ容量を一覧表示。
  - 差分レビュー結果をExcel/CSV形式でワンクリック出力。

### 7. 💾 プロジェクト永続化 (`.fmorph`) & 移行スクリプト自動生成
- **プロジェクト保存/読込**: 設計途中の仮想ツリー、N:1紐づけ、ACL設定を独自形式 **`.fmorph`**（JSON構造化）で安全に永続化。
- **Robocopy 自動生成**: N:1統合マッピングや各フォルダの移行パスに対応した最適化バッチ（マルチスレッド `/MT:16`、アクセス権同期 `/COPYALL`）を自動出力。
- **PowerShell ACLスクリプト自動生成**: Windowsの高度なアクセス権を含むNTFS ACLを新環境へ一発適用する `.ps1` を出力。

## 🚀 起動方法

### 方法1: exeを直接ダブルクリック（推奨）
プロジェクトフォルダ直下の **`FolderMorpher.exe`** をダブルクリックしてください。

### 方法2: バッチファイルから起動
プロジェクトフォルダ直下の **`FolderMorpher.bat`** をダブルクリックしてください。

## 🛠️ 技術スタック
- **言語 / ランタイム**: C# (.NET 8.0 Windows Desktop SDK)
- **UIフレームワーク**: WPF (Windows Presentation Foundation) / Fluent Light Design
- **ディレクトリサービス**: `System.DirectoryServices` (LDAP / ADSI ダイレクトクエリ)
- **ストレージAPI**: Win32 `GetDiskFreeSpaceEx` (P/Invoke)、`System.IO.Enumeration`
- **セキュリティ**: `System.Security.AccessControl` (NTFS ACL / SDDL)
- **保存形式**: `.fmorph` (UTF-8 JSON Project Schema)
