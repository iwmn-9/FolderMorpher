# v1.0.1 外部レビュー対応

評価対象のv1.0.0から、誤変更・データ消失・検索漏れに直結する指摘を優先して修正した。評価点の再採点は行っていない。設計理由はADR 145/146、依存と通知は [DEPENDENCIES.md](DEPENDENCIES.md) が正本。

| 指摘 | 改善・実装 | 主な検証 |
| --- | --- | --- |
| AD主体のSID/ドメイン消失 | 選択・RPC・保存・計画・適用でSIDを維持。旧名前ACEはHostのCheckでSID固定 | SIDが異なる同名主体、表記が違う同SID、ACL実機回帰/IPC |
| N:1の逐次ミラーによる先行ファイル削除 | 全コピー元の統合期待一覧を先に作り、コピー成功後に計画した余剰だけ削除 | 2ソース統合の実コピー、余剰削除、衝突時の原本/対象非変更 |
| Wave分割で親直下が欠落 | 親残余単位を追加 | 分割計画・ルート直下の実コピー |
| 移動した子を親でも二重コピー | 全ソースの元パス包含から除外を解決 | 別Waveへ移した子の一回コピー・後続Waveからの保護 |
| BATのechoリダイレクト/特殊文字 | パスはJSON、echoは固定文字。遅延展開なし、引用したスクリプト呼出し | 空白・&・!を含む実ソースでランナーを実行 |
| Office XMLの生置換、通常セルの誤変更 | 外部Relationship/数式をXMLとして変更し全XMLを再解析 | &/日本語を含む置換、通常セル保護、VBA混在回帰 |
| 無効な画像長辺で原本を縮退 | Core/UIで寸法・品質検証、出力寸法を確認 | 0/負数/範囲外拒否、実PNG縮小・透過検証 |

## 改善提案への対応範囲

- **A 実行計画**: 解決済みコピー単位・宛先・Wave・除外をJSONへ固定。実行時Checkで衝突・余剰対象を確定し、同一プロセス内のCommit/Verifyへ渡す。
- **B 不確実性の表示**: 未確認容量、OCR未実行/部分処理、検索総数と保持上限を分離。
- **C リンク移行連携**: 旧/新パスとWaveの対応CSVをパッケージに出力し、既存リンク修復へ渡せるようにした。リンク依存グラフの自動走査・修復計画統合は未実装。
- **D 証跡**: CUTOVERの期待件数・削除対象・Verify方式をJSON記録し、手順書/Excelを同じ意味へ更新。宛先の全文ハッシュ検証・ACL/所有者/共有権限を含む包括的な移行証明は未実装。
- **E 定期監査**: 今回は追加しない。保存先・頻度・通知・常駐寿命を伴う独立機能として扱う。

## 検証範囲と制約

ビルド、8ドメイン回帰、通知表記ゲート、配布単一EXEの実IPCをリリース条件とする。移行スクリプトは隔離したローカル試験データで実行し、実共有のデータは変更しない。UNCの実サーバー試験とクリーンWindowsでの試験は今回未実施。

移行Verifyは原本のサイズ/日時と宛先種別/サイズであり、全文ハッシュ一致を保証しない。切替中の書き込み停止が必要。PowerShell実行ポリシーは回避せず、組織で許可された実行環境を使う。OCRは推定文字列であり、64MiB入力・40MP画像・100PDFページ等の上限がある。Hostの通常終了で展開資産を回収するが、強制終了/OS障害後の残存は保証しない。
