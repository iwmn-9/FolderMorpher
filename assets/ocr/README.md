# Embedded PP-OCRv6-small runtime

These tar+gzip chunks contain the audited Filunest small OCR runtime, its fixed model/config files, embedded Python and native dependencies, notices, and required source archives. `manifest.json` records source inventory provenance and chunk hashes. Runtime extraction is session-only; no network download occurs.

Regeneration and license details: [dependencies](../../docs/DEPENDENCIES.md). Generate only from a verified `bundle.json` inventory with `tools/Prepare-OcrBundle.py`. Do not include generated bytecode, PDBs, personal paths, or unreviewed runtime additions.
