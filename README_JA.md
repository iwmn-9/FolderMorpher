## 🛡️ プロダクト操作哲学：二元論 ＆ 3段ロケット原則

FolderMorpher は、管理者の探索スピードを最大限に引き上げつつ、ディスク書き込み時の事故を徹底的に防止する「二元論アーキテクチャ」を採用しています：

| 区分 | 対象機能 | UX挙動 |
| :--- | :--- | :--- |
| **観測・生成系**<br>*(覗く・出力するだけ)* | • 容量スキャン ＆ 0秒ツリー参照<br>• AD逆引き実効アクセス権監査<br>• 休眠・重複ファイル棚卸し<br>• Excel / CSV 台帳出力<br>• 安全退避バッチ (.bat) ＆ GPOスクリプト (.ps1) 出力 | **ノーガード・即時実行**<br>(確認ダイアログやDry-runを挟まず、探索テンポを一切阻害しない) |
| **介入系**<br>*(ディスク実態を変更する)* | • **権限コントロール（Live ACL直接変更）**<br>• **スケルトン先行展開（空フォルダ＋ACL作成）**<br>• **ショートカット一括修復（.lnk直接書き換え）**<br>• **メディア最適化（写真直接上書き縮小）** | **Plan First（3段ロケット）**<br>`[ チェック ]` ➔ モーダル **`⚖️ 変更点`**（Before/After事前確認） ➔ `[ 適用 ]` ➔ カーネル実態 **Verify（自動検証）** |

## 🌟 6大コア機能

### 1. 📊 容量分析 & 監視 (Storage Explorer - 0秒ツリーキャッシュ)
![Tab 0: 容量分析](docs/screenshots/tab0_storage.png)
- **⚡ 0秒ツリーキャッシュ ＆ バックグラウンド自動差分スキャン**: スキャン開始時、前回キャッシュがあれば「0秒」で前回のツリー構造を即座に全展開。バックグラウンドで最新走査を実行し、容量が変化したフォルダに増減バッジ（`▲ +2.4GB` / `▼ -500MB`）を自動付与。
- **⚡ 超高速NTFS MFT直読みスキャン & 3段ハイブリッド自動フォールバック**: 管理者権限でのローカルNTFSドライブ（またはファイルサーバー直接実行時）において、ディスク管理領域（`$MFT`）を直接バイナリ解析し、数百万ファイルを数秒で一括インデックス。完全読み取り専用（`GENERIC_READ`・排他ロックなし）。UNC共有や一般権限時は自動で通常並行スキャンへシームレスにフォールバック。
- **全体占有率メーター（二重加算防止）**: スキャンルート全体（100%）に対する絶対シェアと、右ペインでの選択フォルダ直下シェアを完全分離。
- **Top 10 ランキング ＆ エクスプローラー直行**: 肥大化の元凶ファイルを特定し、ダブルクリックで対象ファイルを青く選択した状態でエクスプローラーを即時起動。
- **マルチタブ同時スキャン**: 複数ドライブや別サーバー（UNC共有 `\\server\share`）を並行監視。

---

### 2. 🛡️ 権限コントロール & 逆引き監査 (Live ACL Studio)
![Tab 1: Live ACL](docs/screenshots/tab1_liveacl.png)
- **`AclChangePlan` パイプライン貫通**: 差分プレビューと本番適用で同一の実行計画インスタンスを貫通させ、PreviewとCommitのロジック乖離を物理的に根絶。
- **縦一列 2行カードUI**: 1行目にアカウント表示名を横幅100%開放、2行目にアカウントID、権限、適用先、🔒継承バッジを整列。ADパレットからのD&D追加、枠外ドロップによる直感的解除を完備。
- **継承変更警告バナー**: 継承を無効化する際、親から明示ACEへ昇格・保持される件数を明示し、重大なアクセス権遮断事故を事前警告。
- **セマンティック正常性検証 (True Verify)**: 適用直後、OSカーネルから再取得した実態ACEと期待値を多重集合突合し、完全一致（`✅ 正常`）を自動検証。
- **🔍 ユーザー/グループ逆引き権限インスペクター（Canonical DACL評価・多重入れ子ADグループ完全対応）**: 対象ユーザーやセキュリティグループを選択し、ファイルサーバー全体を逆引きスキャン（探索階層は無制限/指定可能）。グループの多重ネスト（`LDAP_MATCHING_RULE_IN_CHAIN` / tokenGroups）を本人ID汚染なしで完全解決。Windowsの正規DACL評価順序（子の明示的Allowは親の継承Denyより優先）を忠実に再現し、実際にアクセスできる全フォルダーと権限種別、付与経路を可視化。ハイパーリンク付きExcel監査台帳を1クリック生成。
- **SDDL直前自動スナップショット（即座に復元）**: 適用直前の完全なDACL SDDLを自動退避。「↩️ バックアップ復元」でいつでも直前の状態へ原子的ロールバック可能。

---

### 3. 🚀 移行スタジオ & スケルトン先行展開 (Simulation Studio)
![Tab 2: 移行スタジオ](docs/screenshots/tab2_simulation.png)
- **仮想ツリー設計 ＆ N:1統合マッピング**: 「旧営業A」「旧営業B」を新環境の「営業第一部」へまとめる統合ツリーを視覚的に設計。階層フォルダの再帰的D&DとACL自動引き継ぎに対応。
- **スケルトン先行展開（ガワ先行作成）**: 大容量データ転送の前に、空フォルダ構造と設計済みNTFS ACLだけを新サーバーに先行作成。モーダル **`⚖️ 変更点`** で差分を確認後に `[ ⚡ 適用 ]` し、実在Verify。
- **Diffインスペクター**: 移行前後（Before/After）の変化点（新規・移動・統合・ACL差分）をカラーバッジでレビューし、Excel出力。
- **Robocopyモード分離**: 「新設計ACL維持モード（`/COPY:DAT`）」と「旧環境ACL完全維持モード（`/COPYALL`）」を明示分離し、新設計ACLの上書き破壊を防止。

---

### 4. 🔗 リンク一括修復 ＆ GPOスクリプト生成 (LinkFixer)
![Tab 3: リンク一括修復](docs/screenshots/tab3_linkfix.png)
- **切断ショートカット（`.lnk`）の一括直接修復**: モーダル **`⚖️ 変更点`** で置換対象と新旧パスを確認し、`.bak` 安全バックアップを自動生成しながら直接書き換え ➔ 実態Verify。
- **Office内部リンク・マクロ修復**: Office COMを起動せず、OpenXML（.xlsx/.xlsm）内部XMLを直接高速走査。外部ブック参照数式やワークシートリンクを安全置換、VBA内の旧UNCパスを検知・警告（`~$` ロック検知付き）。
- **GPOログオンスクリプト生成（`.ps1`）**: 全社PCのデスクトップ・マイドキュメント等のショートカットをサイレント一括修復する管理者用スクリプトをワンクリック生成。

---

### 5. 🧹 断捨離・健全化 (Audit & Hygiene - 大容量ストレージ監査)
![Tab 4: 断捨離・健全化](docs/screenshots/tab4_audit.png)
- **重複ファイル・休眠ファイルの徹底抽出**:
  - **重複ファイル検出**: ファイルサイズ絞り込み ➔ SHA256暗号学的ハッシュによる完全一致判定。無駄容量を算出。
  - **休眠ファイル抽出**: 3年以上更新されていない放置データ（最終更新日時基準）を抽出。
  - **パス長（260字超）＆ 移行禁則文字チェック**: クラウド（SharePoint/Box）やWindows移行でエラーになる記号や長大パスを事前洗い出し。
- **スマート一括選択 ＆ 原本候補保護聖域**: 重複原本（`IsOriginalCandidate`）を厳格に保護しながらコピーファイルのみを一括選択。
- **原本保護安全ガード付き物理完全削除**: チェックされた不要ファイルを直接完全削除（読み取り専用属性解除・原本候補除外警告ダイアログ付き）。
- **安全第一の運用ポリシー**: 各部署提出用の**「棚卸し台帳（Excel/CSV）」**および**「安全退避（Archive移動）バッチ」**を1クリック生成。

---

### 6. 🖼️ メディア・オプティマイザ (Media Optimizer)
![Tab 5: メディア最適化](docs/screenshots/tab5_media.png)
- **聖域保護（自動スキップ）**: `_Master`, `印刷用`, `RAW`, `.psd`, `.ai` などのフォルダ名・プロ用拡張子は自動スキップ。
- **写真・画像の直接上書き最適化**: スマホ写真（JPEG）を長辺2560px・85%品質で直接上書き軽量化（**約90%の容量削減**）。PNGはアルファ透過を100%保持した最適化を実行。撮影日時・更新日時・作成日時・Exif・回転情報を完全保持。
- **事前チェック ＆ 実態Verify**: モーダル **`⚖️ 変更点`** で対象写真と聖域除外数を確認して適用、削減容量を自動検証。
- **巨大モンスター動画Topランキング**: ギガ単位を消費する動画ファイルを容量順に抽出し、**夜間GPUエンコード（H.265 / NVENC / QSV）バッチ**を出力。

## 🚀 ダウンロード & 起動方法

### 動作要件
- OS: Windows 10 / Windows 11 / Windows Server 2016 以降 (64-bit)
- 追加ランタイムやインストーラーは**一切不要**（単一EXEに全て同梱）。

### 起動手順
1. [**Releases**](../../releases) から最新の単一実行ファイル（`FolderMorpher.exe`）をダウンロードします。
2. そのままダブルクリックして起動してください。インストーラーやレジストリ汚染はありません。

## 🛠️ 技術スタック & アーキテクチャ

- **言語 / ランタイム**: C# 12 / .NET 8.0 Windows Desktop SDK (Self-Contained 単一実行ファイル)
- **UIフレームワーク**: WPF (Windows Presentation Foundation) / Modern Fluent Light Design
- **ディレクトリサービス**: `System.DirectoryServices` (LDAP / ADSI)
- **セキュリティ**: `System.Security.AccessControl` (NTFS ACL / SDDL)
- **Excel生成**: `ClosedXML` (OpenXML直接バイナリ生成)
- **画像エンジン**: WIC (Windows Imaging Component / ハードウェアアクセラレーション)
- **品質保証ゲート**: 全28項目のヘッドレス自動回帰テストスイート（`--test-regression`）による常時検証。
- **アーキテクチャ規約**: [`AGENTS.md`](AGENTS.md) にてサービス層とUI層を疎結合に保つADR（設計判断）を厳格に管理。
